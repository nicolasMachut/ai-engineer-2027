# AI Engineer 2027 · learning track

A 12-month, 15 h/week learning track to become a senior AI engineer on the JVM (Java, Spring AI, LangChain4j) with working Python: LLM fundamentals, RAG, agents, MCP, evals, security, production on AWS, certifications and career.

**Live site: https://nicolasmachut.github.io/ai-engineer-2027/**

## What is inside
- 22 modules with theory, exercises, quizzes, resources and English practice (including data foundations: SQL, pipelines, data quality)
- Capstone projects built for real personal use, each with senior-level criteria (evals, deterministic logic, threat model, ADRs, usage metrics)
- Certification plan: free certificates, AWS Certified Generative AI Developer Professional (AIP-C01), Claude Certified Architect
- Spaced-repetition review of quiz questions
- Optional interview prep: 10 AI system design problems, behavioural questions, timeboxed take-home, mock interview prompt
- Proof ledger, market intel (US, France, Switzerland, Europe), career kit, gamification (XP, levels, badges)

Content is checked against official sources and refreshed monthly.

Single self-contained HTML file, no build step, no tracking. Progress is stored in your browser (localStorage); use Settings to export or import a backup.

Built with Claude as a co-author, curated and maintained by me.
